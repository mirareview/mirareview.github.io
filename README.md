# Anonymous website upload bundle

`site/` is the complete GitHub Pages artifact. All playback and downloads use MP3 (320 kbps).
Original WAV/FLAC files stay local and are not included. No separate Release storage is needed.
Only publish under the author-designated anonymous account.
Push site/ and .github/ with a neutral commit identity, configure Pages for GitHub Actions, and run the workflow.
The entire repository name and history must be anonymous. No personal account fallback is authorized.
