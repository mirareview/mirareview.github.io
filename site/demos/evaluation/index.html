Rating instructions / 评分须知

Judge intent alignment rather than personal preference. System ratings use 1–5 (clearly misaligned → very well aligned), with one or more best candidates. Item ratings use 1–20; uncertain means insufficient audible evidence, not a midpoint.

请根据意图对齐而非个人偏好判断。整体评分为 1–5 分，可选多个并列最佳。逐项评分为 1–20 分，“不确定”表示证据不足，不是中间分数。
